# Setting up a POS system for a small business

A general checklist for installing a point-of-sale (POS) system in a shop or restaurant. Steps differ by product, so follow the vendor's instructions where they differ from this list.

## Before the visit

- [ ] Ask what the business sells and how it takes payments (cash, card, other)
- [ ] List the hardware needed: computer or tablet, receipt printer, cash drawer, barcode scanner, card terminal
- [ ] Confirm the shop has working internet, and find out whether the POS also works offline
- [ ] Get the product list with prices, or agree how to enter it

## Network

- [ ] Put POS devices on a reliable connection (a cable is better than Wi-Fi where possible)
- [ ] Give the POS computer and the receipt printer fixed addresses, or reserve their addresses in the router, so they do not change
- [ ] Change the router's default administrator password
- [ ] Keep customer Wi-Fi separate from the network the POS uses

## Install and configure

- [ ] Install the POS software and apply updates
- [ ] Enter the business name, address, tax settings, and receipt text
- [ ] Add products, prices, and categories
- [ ] Create a separate login for each staff member, with limited permissions for cashiers
- [ ] Connect and test the receipt printer, cash drawer, barcode scanner, and card terminal

## Test before opening

- [ ] Run a sale by cash and a sale by card
- [ ] Run a refund and a discount
- [ ] Print a receipt and scan a barcode
- [ ] Close the day and check that the totals match
- [ ] Unplug the internet and confirm what happens during an outage

## Backup and safety

- [ ] Turn on automatic backups of sales data, and confirm one backup can be restored
- [ ] Keep the system and the POS software updated
- [ ] Write down who can reach the vendor's support and how

## Handover

- [ ] Show staff how to sell, refund, open and close the register, and print reports
- [ ] Leave a one-page guide with the support contact details
- [ ] Agree who the shop calls first when something breaks
