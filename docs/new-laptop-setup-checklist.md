# Setting up a new laptop for an employee

Use this for onboarding. Copy the list into the ticket and tick items off as you go. Check your company's own policy before using any step here.

## Before the employee arrives

- [ ] Record the laptop model, serial number, and asset tag
- [ ] Update the operating system and install all pending updates
- [ ] Update the firmware (BIOS or UEFI) if the manufacturer offers an update
- [ ] Name the computer using the company naming rule

## Accounts and security

- [ ] Create the employee's accounts (email, company systems) and give them a temporary password
- [ ] Set up multi-factor authentication
- [ ] Turn on disk encryption (BitLocker on Windows, FileVault on Mac) and store the recovery key where the company policy says
- [ ] Confirm antivirus is installed, updated, and running
- [ ] Confirm the firewall is on
- [ ] Give the employee a standard account, not an administrator account, unless the role needs one

## Software

- [ ] Install the standard company software (office suite, browser, chat and video calling tools, PDF reader)
- [ ] Install the software for the employee's role
- [ ] Sign in to each tool once to confirm access works

## Hardware and network

- [ ] Connect to the office Wi-Fi and confirm internet access
- [ ] Add the network printers the employee needs and print a test page
- [ ] Test the camera, microphone, speakers, keyboard, and charger
- [ ] Check that a docking station or second monitor works if the employee uses one

## Handover

- [ ] Show the employee how to sign in, change the temporary password, and where to ask for help
- [ ] Explain the rules for storing files and backing them up
- [ ] Have the employee sign the equipment record
- [ ] Update the asset list with the employee's name and the date
- [ ] Close the ticket with notes on anything unusual

## When an employee leaves

- [ ] Disable the accounts and remove access on the last day
- [ ] Collect the laptop, charger, and any accessories
- [ ] Back up what the company needs to keep, then wipe the laptop before it is reused
- [ ] Update the asset list
